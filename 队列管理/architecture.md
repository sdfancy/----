## 🔄 系统架构与连接设计

### 双TCP连接架构
连接1（入队）：PLC:9999 → 软件，负责相机拍照和数据入队
连接2（出队）：PLC:9009 → 软件，专门负责机械臂出队命令
相机连接：软件 → 相机，接收点位数据
机械臂连接：机械臂 → 软件，请求和接收数据

## 📊 完整业务流程

### 入队流程

#### 阶段1：初始触发
1. **PLC连接1发送**：01 + 计数 + 指针 + 其他数据
2. **软件解析**：按2字节单位解析，提取命令01
3. **软件动作**：将01发给相机触发拍照

#### 阶段2：机械臂1数据入队
4. **相机传输**：发送机械臂1的点位数据
5. **软件处理**：解析相机数据，创建队列项并入队
6. **软件反馈**：向PLC发送字符'1'

#### 阶段3：机械臂2数据入队
7. **PLC连接1回复**：11 + 计数 + 指针 + 其他数据
8. **软件解析**：提取命令11
9. **软件动作**：将11发给相机触发机械臂2数据传输
10. **相机传输**：发送机械臂2的点位数据
11. **软件处理**：解析相机数据，创建队列项并入队
12. **软件反馈**：向PLC发送字符'2'

#### 阶段4：入队完成
13. **PLC连接1回复**：12 + 计数 + 指针 + 其他数据
14. **软件解析**：入队流程结束

### 出队流程

#### 阶段5：出队信息接收与解析
15. **PLC连接2发送**：4字节出队信息 [机械臂1指针(2字节)][机械臂2指针(2字节)]
16. **软件解析**：按2字节分割，提取各机械臂指针
17. **指针比较**：与上次记录的指针值对比

#### 阶段6：指针变动检测与缓存
18. **变动检测**：如果机械臂1指针变化 → 触发出队1流程
19. **数据定位**：根据变化的指针在队列中查找对应数据项
20. **缓存准备**：将找到的数据放入对应机械臂的缓存区
21. **状态标记**：标记为"等待机械臂请求"

#### 阶段7：机械臂数据交互
22. **机械臂请求**：机械臂发送字符串"data"请求数据
23. **数据传输**：从缓存区取出数据发送给机械臂
24. **PLC同步**：向PLC发送字符串"data"
25. **完成确认**：机械臂回复字符"1"，软件转发给PLC
26. **状态更新**：标记队列项为该机械臂已处理

## 🔧 核心技术实现

### 数据格式规范
入队数据：01/11/12 + 计数(2字节) + 指针(2字节) + 其他数据
出队数据：机械臂1指针(2字节) + 机械臂2指针(2字节)
相机数据：点位信息(float32格式) + 结束标记'E'
plaintext

### 缓存机制设计
- **独立缓存区**：每个机械臂拥有专属数据缓存
- **状态跟踪**：完整记录每个数据项的处理状态
- **重复支持**：缓存数据保留至确认完成，支持重复请求

### 并发处理能力
- **多机械臂并行**：支持多个机械臂同时进行出队操作
- **线程安全**：使用锁机制保证数据一致性
- **异步处理**：相机数据接收采用异步方式
