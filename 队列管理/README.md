# 队列管理系统（需求与流程说明）

本项目用于协调 PLC、相机、机械臂1、机械臂2 的联动，核心目标是：

1. 保证 PLC 脉冲队列与软件数据队列严格一一对应。
2. 在设备离线、相机超时等异常情况下，流程仍可继续，不错位。
3. 对外统一使用增强版接口与流程。

## 1. 系统角色与连接

- PLC -> 软件（入队口）：`9999`
- PLC -> 软件（出队口）：`9009`
- 软件 -> PLC（反馈口）：`9009`
- 软件 -> 相机：`CAMERA_TCP_CONFIG`
- 软件 -> 机械臂1/2：`ARM_TCP_CONFIG`
- HMI：`http://127.0.0.1:8090`

说明：
- 软件内部维护两个数据队列（机械臂1队列、机械臂2队列）。
- HMI 里的“主队列”是总览视图，不是第三个独立业务队列。

## 2. 需求基线（已确认）

### 2.1 队列模型

- 真实业务是“一个工件、两套机械臂数据”。
- PLC 维护两个脉冲队列；软件也维护两个数据队列。
- 两个数据队列使用同一入队时机、同一入队指针（pointer）。
- 队列溢出策略固定为：覆盖最老数据（并记录告警）。

### 2.2 PLC 命令语义（入队口）

- `01`：创建新工件（真正入队事件）。
- `11`：绑定最近一次有效 `01` 的上下文（忽略其自带计数）。
- `12`：流程结束信号，不创建新工件。

### 2.3 相机触发协议

- 非并发模式：16位整数二进制帧。
- 并发模式：ASCII 文本帧（如 `CMD:01,COUNT:3`）。
- 命令值原样透传给相机（01/11/12）。

### 2.4 机械臂协议与 PLC 反馈

- 机械臂发 `data`：软件下发对应缓存数据，并向 PLC 回 `XN`。
- 机械臂发 `1`：软件标记完成，并向 PLC 回 `XD`。
- `X` 为机械臂编号（`1` 或 `2`），`N`=已发未完成，`D`=完成。
- 反馈固定走 `9009`。

### 2.5 超时策略

支持两种模式（可配置切换）：

1. `cycle_timeout`
- 下一次 `01` 到来时，若上一轮仍有未收到相机数据的槽位，则填默认值。

2. `dequeue_timeout`
- 当该元素“应该出队”（PLC 指针到达、触发出队）时仍无相机数据，则填默认值再出队。

默认值（暂定）：
- 机械臂1：`(1000)E`
- 机械臂2：`(2000)E`

晚到数据处理：
- 若元素已超时填默认或已出队，后续相机晚到真实数据直接丢弃。

### 2.6 重复请求策略

- 机械臂重复发送 `data`：允许重复下发同一缓存数据，直到完成确认。

## 3. 完整流程

### 3.1 入队流程

1. 传感器触发后，PLC 计算目标脉冲并入脉冲队列，计数器+1。
2. PLC 向软件发送入队报文：`命令 + 计数 + 入队指针`。
3. 软件解析命令并触发相机（非阻塞，不影响其他模块）。
4. 相机回包后，软件将数据写入对应机械臂队列项（同一 pointer）。
5. 队列项保存状态、时间戳、来源（camera/default）等信息。

### 3.2 出队流程

1. PLC 脉冲达到目标后，向软件发送出队指针（arm1/arm2）。
2. 软件为变化的指针准备出队缓存。
3. 机械臂收到 IO 后发 `data` 给软件。
4. 软件返回缓存数据给对应机械臂，并反馈 PLC：`1N` 或 `2N`。
5. 机械臂收到数据后发 `1`。
6. 软件标记完成并反馈 PLC：`1D` 或 `2D`。

## 4. 异常与容错

- 除 PLC 外设备离线：
  - 仍按 PLC 入/出队推进状态，保证队列与脉冲不乱序。
- PLC 离线：
  - 软件静默等待，恢复连接后继续按 PLC 指针驱动。
- 机械臂断线：
  - 机械臂控制器支持自动重连。
- 相机超时：
  - 根据当前超时模式填默认值，允许业务继续。

## 5. 关键配置（`config/settings.py`）

- `PLC_TCP_CONFIG`：PLC 双端口参数。
- `CAMERA_TCP_CONFIG`：相机地址、端口、超时。
- `ARM_TCP_CONFIG`：机械臂1/2地址、端口。
- `QUEUE_CONFIG`：队列长度等基础参数。
- `QUEUE_RUNTIME_CONFIG`：
  - `timeout_mode`：`cycle_timeout` / `dequeue_timeout`
  - `camera_correlation_mode`：`sequential` / `counted`
  - `default_payloads`：默认值数据
  - `drop_late_camera_data`：是否丢弃晚到数据
- `HMI_CONFIG`：可视化页面开关与端口。

## 6. 运行与联调

### 6.1 启动主程序

```powershell
.\.venv\Scripts\python.exe src/main.py
```

### 6.2 启动设备模拟器

```powershell
.\.venv\Scripts\python.exe tools/device_simulator.py
```

模拟器支持：
- PLC 三按钮：传感器触发、机械臂1出队、机械臂2出队
- 相机模拟回包
- 机械臂模拟 `data/1`
- 实时显示 `1N/1D/2N/2D`

建议顺序：
1. 先启动模拟器（相机/机械臂服务先监听）。
2. 再启动主程序。
3. 在模拟器点击“连接PLC到软件”后开始联调。

## 8. 当前版本说明

- 当前默认相机关联模式为 `sequential`。
- 并发相机场景可切换到 `counted` 模式。
- `11/12` 命令的 PLC 计数按需求忽略，统一绑定最近有效 `01` 上下文。
